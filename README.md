# DOM Messenger 1.3

Windows-focused DOM build. Version 1.3 adds local account creation/login, logout, channel creation, message editing/deletion, reply and local persistence.

## Build
Run `BUILD-DOM.bat` or `scripts\BUILD-DOM.ps1`.

The app stores local demo data under `%APPDATA%\DOM\dom_data.json`. This is a local desktop demo; multi-device accounts/channels require a backend.
