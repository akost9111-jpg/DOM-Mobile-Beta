# DOM Messenger

Кроссплатформенный MVP мессенджера DOM на Flutter.

## Платформы
- Android
- iOS
- Web
- Windows
- macOS
- Linux

## Возможности демо
- Главный экран со списком чатов
- Поиск
- Экран диалога
- Отправка локальных сообщений
- Реакции
- Профиль пользователя
- Настройки
- Нижняя навигация

## Запуск
1. Установите Flutter 3.x.
2. Выполните `flutter pub get`.
3. Запустите `flutter run -d chrome` для Web или выберите Android/iOS/Desktop устройство.

Это UI/MVP-основа. Для production нужны backend, авторизация, база данных, push-уведомления, загрузка файлов и WebRTC-звонки.
